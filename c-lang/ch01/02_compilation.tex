\section{Компиляция}

В операционной системе семейства Unix необходимо поместить программу в файл,
имя которого имеет окончание \texttt{.c}, например \texttt{hello.c}.

Затем ее следует скомпилировать с помощью следующей команды:

\begin{verbatim}
$ cc hello.c
\end{verbatim}

В результате компиляции будет создан исполняемый файл \texttt{a.out}.

Теперь этот файл можно запустить на выполнение командой:

\begin{verbatim}
$ ./a.out
\end{verbatim}

В результате его выполнения будет выведена строка:

\begin{verbatim}
Hello, world!
\end{verbatim}
